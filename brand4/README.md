# brand4 · 좋은 날은 가까이에

brand2에서 분기한 독립 브랜드 매거진 시안입니다. 원본 brand2는 수정하지 않았습니다.

## 현재 구성

- 글과 사진을 동등한 비중으로 배치한 표지와 브랜드 이름 소개
- 데스크톱: 자연스러운 세로 스크롤을 따라 고정 사진이 교차 전환되는 세 개의 일상 장면
- 모바일: 고정 화면 없이 사진과 글을 장면별 세로 배치
- 13개 연도를 선택하는 일정한 높이의 연혁 뷰어, 전체 연혁 펼치기
- 같은 높이로 정렬한 제품 쇼케이스와 마무리 문구

## 수정 위치

`index.html`, `concept.css`, `concept.js`, `history-data.js`.
공통 헤더·모션 제어는 `/shared/concept-base.css`, `/shared/concept-runtime.js`를 사용합니다.
복사된 이전 `brand2.css`, `brand2.js`는 보관 파일이며 로드하지 않습니다.
역사·사진 출처는 기존 자료를 계승했고 각 참고 이미지의 성격을 표시합니다.

## 실행 및 검증

루트에서 `node start-preview.mjs` → http://127.0.0.1:4175/brand4/

Chromium에서 320·390·768·1440px 폭 및 1366×650 화면 확인.
장면 0→1→2→1→0의 사진·번호 동기화, 연도 빠른 연속 선택, Home/End 키,
13개 연도 전환 시 모바일·데스크톱 패널 높이 유지, 모션 감소, 로컬 리소스 및 콘솔 오류를 확인했습니다.
모션 정지와 OS 모션 감소는 문서 높이 및 현재 스크롤 위치를 바꾸지 않습니다.
