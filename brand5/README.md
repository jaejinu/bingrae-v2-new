# brand5 · 오늘의 작은 기쁨

brand3에서 분기한 체험 시안입니다. 원본 brand3는 수정하지 않았습니다.

## 현재 구성

표지에서 고른 기분이 일상 사진·문구 → 제품 쇼케이스 → 나의 카드로 이어집니다.
신나게/다정하게/느긋하게 선택 상태는 세 곳의 선택 버튼에 동기화됩니다.
연혁은 가로 스크롤·버튼·키보드·마우스 드래그로 탐색합니다.
카드는 선택한 기분과 사용자 문구, 색상으로 1200×1200 PNG를 생성합니다.

## 수정 위치

`index.html`, `concept.css`, `concept.js`.
공통 헤더·모션 제어·이미지 전환은 `/shared/concept-base.css`, `/shared/concept-runtime.js`.
복사된 brand3의 기존 CSS/JS는 보관 파일이며 로드하지 않습니다.

이미지를 미리 디코딩한 뒤 관련 상태를 함께 바꾸며, 연속 선택은 마지막 요청만 반영합니다.
사용자가 직접 입력한 문구 및 선택한 색상은 기분을 바꿔도 유지합니다.
모션 정지·OS 모션 감소 시에도 문서 높이를 유지합니다. 화면 밖/비활성 탭에서는 표지 회전을 멈춥니다.
사용자 문구는 서버로 전송하지 않으며 textContent와 Canvas로 표시합니다.

## 실행 및 검증

루트에서 `node start-preview.mjs` → http://127.0.0.1:4175/brand5/

Chromium에서 320·390·768·1440px 폭 확인.
빠른 기분 연속 선택의 최종 상태, 장면·제품·카드 동기화, 사용자 문구/색상 유지,
모션 정지 시 스크롤 위치·문서 높이 유지, 연혁 End 키 및 끝 버튼 상태,
PNG 다운로드, 로컬 리소스 및 브라우저 콘솔을 확인했습니다.
